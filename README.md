# 주간 메이플 · 웹 (아이폰용)

안드로이드 앱(`JuboLedger`)의 아이폰 버전입니다. 설치 없이 링크로 쓰고,
사파리에서 **홈 화면에 추가**하면 아이콘이 생기고 주소창 없이 앱처럼 열립니다.

계산은 안드로이드 앱과 같습니다 — 넥슨 스케줄러를 읽어 보스와 클리어 상태를 채우고,
결정석 값을 파티 인원으로 나눠 더하고, 목요일 0시(주간)와 매월 1일(검은 마법사)에 초기화합니다.
기록과 키는 **이 브라우저 안에만** 저장되고 넥슨 외에는 어디로도 나가지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대와 스타일 |
| `app.js` | 보스 표·가격·날짜 계산·넥슨 API |
| `ui.js` | 화면 그리기와 조작 |
| `test.html` | 브라우저에서 넥슨을 직접 부를 수 있는지 확인 |
| `worker.js` | 중계 서버 (CORS 로 막힐 때만 필요) |

## 맥북에서 먼저 확인하기

파일을 그냥 열면(`file://`) 브라우저가 다르게 굴어서, 작은 서버를 띄워 여는 게 정확합니다.

```bash
cd 이_폴더
python3 -m http.server 8000
```

사파리에서 `http://localhost:8000` 을 엽니다.

- **아이폰 화면 크기로 보기** — 사파리 메뉴 → 개발자용 → 응답형 디자인 모드 (⌘⌥R).
  개발자용 메뉴가 없으면 설정 → 고급 → "웹 개발자용 기능 보기" 를 켜세요.
- **진짜 iOS 로 보기** — Xcode 를 깔았다면 시뮬레이터(iPhone)를 켜고 그 안의 사파리로
  같은 주소를 열면 실제 iOS 사파리에서 확인할 수 있습니다.

## GitHub Pages 로 올리기

1. 파일들을 저장소 **루트**에 올립니다 (저장소는 Public)
2. Settings → Pages → Source `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 가 열립니다

친구에게는 이 주소 하나만 보내면 됩니다.

## 넥슨 직접 호출이 되는지 확인

`<주소>/test.html` 을 열고 API 키를 넣어 **확인하기** 를 누릅니다.

| 결과 | 뜻 | 할 일 |
|---|---|---|
| 🟢 됩니다 | 넥슨이 브라우저 호출을 허용 | 없음. 그냥 쓰면 됩니다 |
| 🔴 브라우저가 막았습니다 | CORS 차단 | 아래 중계 서버 |
| 🟡 CORS 는 통과, 키 문제 | 차단은 없음 | 키만 다시 확인 |

## 중계 서버 (🔴 인 경우에만)

`worker.js` 하나면 됩니다. Cloudflare Workers 무료 등급으로 충분합니다.

1. dash.cloudflare.com → Workers & Pages → Create → Worker
2. 편집기 내용을 `worker.js` 로 통째로 바꾸고 Deploy
3. 나온 주소(`https://…workers.dev`)를 앱의 **더보기 → 연결 설정** 에 넣기

넥슨 요청을 그대로 넘기고 응답에 CORS 헤더만 붙여 돌려줍니다.
`/maplestory/v1/` 경로만 통과시키고, API 키는 지나가기만 하며 저장하지 않습니다.

## 아이폰에서 홈 화면에 추가

사파리로 주소를 열고 → 아래 **공유 버튼** → **홈 화면에 추가**.
크롬이 아니라 **사파리**여야 합니다.

## 안드로이드 앱과 다른 점

**정해진 시각 알림이 없습니다.** iOS 는 웹앱이 꺼져 있는 동안 스스로 알림을 띄우지
못합니다(백그라운드 실행 불가). 수요일 밤 알림처럼 하려면 알림을 밀어줄 서버가 따로 필요해서
지금은 넣지 않았습니다. 나머지 — 캐릭터 불러오기, 스케줄러 동기화, 보스 체크, 파티 n빵,
날짜별 기록, 캐릭터 비중 — 은 같습니다.

사파리가 저장공간이 부족하면 오래 안 쓴 사이트의 데이터를 지울 수 있습니다.
홈 화면에 추가해 두면 그럴 가능성이 크게 줄어듭니다.
